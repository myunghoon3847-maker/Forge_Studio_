# Forge Studio Shortcuts

| 키                 | 동작                |
| ------------------ | ------------------- |
| Q                  | Select              |
| W                  | Move                |
| E                  | Rotate              |
| R                  | Scale               |
| F                  | 선택 frame          |
| Ctrl+Z             | Undo                |
| Ctrl+Shift+Z       | Redo                |
| Ctrl+Y             | Redo                |
| Ctrl+D             | Duplicate           |
| Ctrl+S             | `.forge.json` 저장  |
| Ctrl+G             | Group               |
| Ctrl+Shift+G       | Ungroup             |
| Delete / Backspace | Delete              |
| Shift+클릭         | 다중 선택 추가·해제 |

Input, textarea, select, contenteditable 또는 `role=textbox`에 focus가 있으면 편집 단축키를 실행하지 않는다. Ctrl+S는 Forge Studio 저장이 실제로 시작될 때만 브라우저 기본 저장을 막는다.
